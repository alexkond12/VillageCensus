# Gallery captions

Suggested titles and descriptions for the Modrinth / CurseForge gallery. Upload the images in this order;
`01_banner.png` works well as the featured image.

| File | Title | Description |
|---|---|---|
| `01_banner.png` | Village Census | One ledger that tells you everything about the village around you. |
| `02_features.png` | Three ways to use the ledger | Right-click for a report, sneak + right-click to highlight free beds and workstations, right-click a villager for its card. |
| `03_village_report.png` | Village report | Villagers, professions, beds, workstations, breeding and iron golem readiness within 48 blocks, with hints on what to fix. |
| `04_villager_card.png` | Villager card | Bed and workstation coordinates, last sleep, breeding and golem status of a single villager. |
| `05_free_beds_and_workstations.png` | Free beds and workstations | Free beds sparkle green and free workstations white for 10 seconds. Only you see them. |
| `06_crafting_recipe.png` | Recipe | Book + emerald + feather + ink sac. Found in the Tools & Utilities tab. |

## How the screenshots were made

* Minecraft 26.3, Fabric dev client from this repository, no shaders or resource packs, GUI scale auto, 1920 × 1080.
* A normal survival-generated plains village (world type Default). For the highlight shot the villagers were frozen
  with `NoAI` for a moment so they could not claim the freshly placed beds and workstations before the picture was taken.
* The banner and the feature picture are made from the same screenshots; the title uses a small pixel font drawn
  for this project (no Mojang assets).
